# Arcade

A collection of browser games built with HTML, CSS, and JavaScript.

## Games

- Tic-Tac-Toe
- Memory Match
- Pattern Recall
- Sudoku
- Lights Out
- Checkers
- 2048
- Chess
- Whack-a-Mole

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server.
